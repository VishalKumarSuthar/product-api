# Product API

A simple REST API built with Node.js, Express.js, and MongoDB to perform basic product management operations.

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose

## Setup

```bash
npm install
```

Create a `.env` file and add:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Run the project:

```bash
npm run dev
```

## API Routes

* `GET /api/products`
* `GET /api/products/:id`
* `POST /api/products`
* `PUT /api/products/:id`
* `DELETE /api/products/:id`
